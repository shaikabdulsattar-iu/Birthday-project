# 🎂 Birthday Project

This repository contains simple web code to display a birthday wish page along with a special memory photo.

---

## 💻 What is in this Code?

* **`index.html`**: A clean, responsive webpage with a birthday greeting card layout.
* **Simple Styling**: Built with easy-to-read HTML and CSS for smooth display on phone and computer screens.
* **Custom Photo Card**: Displays a photo centered nicely on the page.
